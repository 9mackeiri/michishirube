# ミチしるべ

Instagram のプロフィールから公式LINEへつなぐランディングページです。

- 公開URL: https://9mackeiri.github.io/michishirube/
- 公式LINEの友だち追加: https://lin.ee/wJWC9oc

## 構成

| ファイル | 内容 |
|---|---|
| `index.html` | ページ本体 |
| `style.css` | 見た目（スマホ前提・パソコンでは中央に480px幅で表示） |
| `assets/` | ページに載せる画像（WebP に縮小済み）と OGP 画像 `og.jpg` |

GitHub Pages（main ブランチのルート）で公開しています。ビルドの手順はありません。ファイルを直して push すると反映されます。
